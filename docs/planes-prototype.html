Traffic sprite prototype

Reference implementation of planes.md, and the twin of lib/planes.py: same projection, same 8.8 fixed-point arithmetic, same pixel-size ladder and layout, same polygon fill. Everything below the projection runs in integers, so the sprite bytes are the bytes the C64 should produce. The strokes renderer is the design this replaced, kept here only so the two can be compared; it is not part of the spec and lib/planes.py does not implement it.
